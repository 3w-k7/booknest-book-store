BookNest - النسخة النهائية Offline

هذه النسخة تعمل بدون إنترنت، وتم تضمين Bootstrap والأيقونات والخطوط داخل مجلد vendor.

لتشغيل المشروع:

1. فك ضغط ملف BookNest-offline.zip بالكامل.
2. افتح مجلد BookNest-final.
3. افتح index.html.
4. لا تنقل أي ملف HTML خارج المجلد.
5. يجب أن تبقى مجلدات css و js و images و vendor بجانب ملفات HTML.

الصفحات:
- index.html: الصفحة الرئيسية
- books.html: صفحة الكتب
- book-detail.html: تفاصيل الكتاب
- cart.html: السلة
- wishlist.html: المفضلة
- account.html: حسابي
- about.html: من نحن
- contact.html: اتصل بنا

المجلدات:
- css/: التنسيقات الخاصة بالمشروع
- js/: التفاعل والسلة والمفضلة والبحث
- images/: صور الموقع
- vendor/: Bootstrap والأيقونات والخطوط المحلية

يمكن فتح index.html مباشرة بدون خادم وبدون اتصال بالإنترنت.
