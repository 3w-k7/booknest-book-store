C:\Users\SONY\Desktop\project\BookNest-final📚 BookNest — Book Store Frontend

A modern and responsive book store e-commerce frontend built to provide a clean and interactive online shopping experience for book lovers.
BookNest focuses on the frontend experience, including browsing books, viewing book details, managing a shopping cart, saving favorites, and navigating between different sections of the store.

✨ Features

📖 Responsive book catalog

🔎 Book search interface

📚 Book details pages

🛒 Shopping cart

❤️ Wishlist / favorites

👤 Account page

📞 Contact page

ℹ️ About page

📱 Responsive design for different screen sizes

🌐 Arabic / RTL interface

⚡ Interactive frontend components

📦 Local assets for offline usage

🛠️ Technologies

HTML5 — Semantic page structure

CSS3 — Styling and responsive layouts

JavaScript — Frontend interactions and functionality

Bootstrap — Responsive UI components and utilities

Bootstrap Icons — Interface icons

Google Fonts — Local font resources

🎯 Project Goal

The goal of BookNest is to demonstrate the development of a complete frontend e-commerce experience using core web technologies.
The project focuses on:

User interface design

Responsive layouts

Frontend interaction

Component organization

Asset management

RTL / Arabic interface support

🚀 Running the Project

No backend or build system is required.
Simply open:
index.html 
in a modern web browser.
All required frontend assets are included locally in the project.
